### 2. LSPR Analyzer (Biomaterial Spectra Classification)
* **Tech Stack:** Python, Streamlit, SciPy, Scikit-Learn, XGBoost
* **Overview:** Built an end-to-end interactive web application for automated feature extraction and classification of biomaterial spectra data from Localized Surface Plasmon Resonance (LSPR) instruments.
* **Impact:**
  * Implemented an automated peak detection algorithm (using heavy Savitzky-Golay smoothing) that reduced peak variance from up to 77 nm to under 5 nm.
  * Extracted 16 physically meaningful features per spectrum, classifying them with ensemble methods (Random Forest, XGBoost) and deploying the pipeline into a real-time Streamlit UI.
